A room is a shared conversation. Everyone in it can see the questions and answers, on purpose. No server sees them.

Run rooms with people you would share a document link with, not with strangers.

## Who sees what

| Who | What they see |
|---|---|
| **The host** | Every question and every answer, always. The host's device reads your message and picks each word of the answer. |
| **Everyone else in the room** | Questions and answers, unless the host limits it (below). |
| **Devices that hold layers** | The hidden state for every token. This is not readable text, but it is not private either (below). |
| **The signaling server** | That devices want to meet, and their network addresses. It carries no model traffic and never sees your messages. |
| **Hugging Face** | Downloads of the model's weights, like any download. |
| **pooled.run** | Nothing from the room. The site is static files. |

## Limit who sees the chat

The host sets **Who sees the chat** in **Room settings**:

| Setting | Effect |
|---|---|
| **Everyone** | Everyone in the room sees the questions and the answers. This is the default. |
| **Only me** | Only the host's screen shows the text. Every device still helps write it. |
| **Whoever asked** | Each answer goes to whoever asked it, and to the host. Every device still helps write it. |

The setting also applies to Code mode and to requests from the [Serve API](/docs/serve).

:::caution[Hidden states are not encryption]
The setting decides which screens show the text. It does not hide your words from the devices that run layers. The hidden state that passes between devices is a lossy form of your text, and published attacks recover much of the text from it. **Assume anyone in the room can read your prompts.**
:::

## What Pooled cannot promise

- **Remote compute is not checked.** A device could send back wrong or altered results, and nothing detects it yet.
- **Weights shared inside the room are not checked either.** A device can take missing layers from another device in the room, and only the length is checked. `?peerweights=0` turns this off, so every device downloads from Hugging Face.
- **Devices learn some things about each other:** names, how much memory each gives, which layers each holds, and timing.
- **Devices see each other's IP addresses** when they connect directly. To hide yours, add a TURN relay under **Network** on the join screen and tick **Always go through the relay**.

Pooled does not use noise or shuffling tricks to hide hidden states. They are known to be breakable and would give a false sense of safety.

## Tools connected through the Serve API

Everything a tool sends goes to the room's host. Coding tools send file contents, and sometimes secrets, so point them only at a room you trust.

- The host's screen shows every API request: the last user message (up to 2000 characters) and the answer.
- The others in the room see it too, unless the host picks **Only me** or **Whoever asked**.
- If the host's page closes, the bridge keeps knocking on the room code for a minute in case the page reloads. Stop the bridge (Ctrl-C) when the room ends.

## What stays on each device

- **Cached weights**, in the browser's cache. Clear them under **Room settings**, **Clear cached weights**.
- **Checkpoints of the conversation**: every device keeps its part of the room's checkpoints on disk, so a reload can pick up where it left off. `?ckptdisk=0` turns this off.
- **Code mode files** live in the host's browser, or in a folder on disk the host picked. Other devices get a read-only copy.
- **A TURN relay's address and password**, if you add one, are saved in that browser only and never go into join links.
