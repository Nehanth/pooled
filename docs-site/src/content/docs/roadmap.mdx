## Priorities

| Priority | Meaning |
|---|---|
| **P0** | Now. Broken, wrong, or the biggest thing holding rooms back. |
| **P1** | Next. Planned and ready to build. |
| **P2** | Later, or needs a design note first. |

Issues get the `area:` label of their section.

## Top of the list

- **SSD expert offload** (P1, [design note](https://github.com/Nehanth/pooled/blob/main/roadmap/32-ssd-expert-offload.md)). Stream a MoE's experts from NVMe when VRAM and RAM can't hold them, the next model size up on a Mac and a PC. Landed: the room node's disk reader and `--disk` on `pooled join` / `pooled host` (steps 2-5), and the tab's disk tier (step 8), which runs Qwen3.8-Flash-Next in a Chrome tab (#368) with batched prompt reading (#400-#405).
- **Batched multi-session decode** (P1, [#72](https://github.com/Nehanth/pooled/issues/72)). Agents with subagents send requests at the same time; today they queue behind each other.
- **Host-authoritative room page** (P1, [#17](https://github.com/Nehanth/pooled/issues/17)). Only the host may load a model or start the room's model; the room node already checks.
- **Reproducible benchmarks** (P1, [#21](https://github.com/Nehanth/pooled/issues/21)). A protocol, one result format and a device matrix; a contributor is taking the first slice.
- **Pinned model revisions** (P1, [#19](https://github.com/Nehanth/pooled/issues/19)), so an upstream re-upload can't mix old and new ranges.

## Shipped recently

As of October 11, 2026, every roadmap line was checked against the code:

- **`@pooled/cli` 0.4:** `pooled serve` with OpenAI and Anthropic endpoints and tool calling, `pooled host` / `join` / `chat` on a native peer, and the OpenClaw plugin ([#4](https://github.com/Nehanth/pooled/issues/4), [#11](https://github.com/Nehanth/pooled/issues/11)).
- **Bigger models:** MoE experts kept in system RAM (`--ram`), so one RTX 5070 PC runs the 35B MoE alone at about 38-45 tok/s.
- **Security:** channel-bound join auth, where keys and passes are proved, never sent.
- **Networks:** the TURN relay, in the browser and now the CLI ([#1](https://github.com/Nehanth/pooled/issues/1)).
- **Speed and sessions:** the prefill kernels ([#2](https://github.com/Nehanth/pooled/issues/2)); checkpoints on disk and prefix reuse across agent turns ([#69](https://github.com/Nehanth/pooled/issues/69), [#73](https://github.com/Nehanth/pooled/issues/73)); GPU sampling ([#26](https://github.com/Nehanth/pooled/issues/26)); the GEMV 8-row fix ([#47](https://github.com/Nehanth/pooled/issues/47)).

## Pick something up

1. Find an item in the roadmap and read its design note, if it has one.
2. Comment on its issue before you start, so two people don't build the same thing.
3. P2 items and anything that changes the protocol, the model output or what peers can see need a design note first. See [Contributing](/docs/contributing#changes-that-need-a-design-note-first).

Benchmark reports from hardware we don't have always help. See [Benchmarking](/docs/contributing/benchmarks#report-numbers-from-your-hardware).
