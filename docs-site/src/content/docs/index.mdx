Your laptop, a friend's desktop and a phone each hold some of the model's layers. Together they run a model none of them could run alone, each on its own GPU in a browser tab.

## How a room works

1. Someone opens [pooled.run/room](https://pooled.run/room) and starts a room. They get a six-character code, like `4TK-G9P`.
2. Other devices join with the code, a link or a QR code. Each one says how much memory it gives the room.
3. Anyone in the room picks a model and presses **Start the model**. The room deals the model's layers out to the devices.
4. Each device downloads only its own layers and runs them on its own GPU through WebGPU.
5. For every token, a small hidden state (10 KB on the 27B, 4 KB on the MoE) passes from tab to tab over direct WebRTC connections. The host turns the result into the next word.

```text
host      embed the last token → hidden state
   ↓ a few KB over WebRTC
laptop    layers 0–21           ─┐
desktop   layers 22–42           ├─ each device runs its layers on its own GPU
phone     layers 43–63          ─┘
   ↓ back to the host
host      final norm → LM head → sample → next token (and draft the ones after it)
```

The **host** is the device that runs the model's first and last steps: it reads your message, holds the tokenizer and picks each word. The room picks it for you, usually the strongest computer.

| Model | Memory the room needs | Context |
|---|---|---|
| Qwen3 1.7B | about 4 GB | 8K, up to 16K |

## What runs where

- **The model runs on your devices.** Pooled uses its own WebGPU kernels, not WebLLM, MLC or llama.cpp.
- **Weights come from Hugging Face**, or from another device in the room that already has them. Each device caches its layers in the browser, so the next start is faster.
- **A signaling server only introduces the devices.** It carries no model traffic and never sees your messages. After that, devices talk to each other directly.
- **The site is static files.** pooled.run serves the page; nothing runs on a server.

:::caution[A room is a shared conversation]
Everyone in a room can see what is asked, on purpose. The devices running layers work on hidden states, and those are not private against a determined peer. Run rooms with people you would share a document link with. See [Privacy](/docs/privacy).
:::
