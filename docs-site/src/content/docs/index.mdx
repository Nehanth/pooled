Duga’s [assistant](/) starts with local chat and explicit browser-only notes, without an account. Its first message downloads about 640 MB of Qwen3 0.6B weights and requires WebGPU. There is no hosted fallback. Private Net ownership enforcement, Global Net, credits, connectors and microphone conversation are not available yet.

The room workspace below is the existing Pooled runtime. Invite links and host-approved room codes work without accounts; local assistant chat and saved notes are not transferred into a room.

The Duga room, powered by Pooled, runs one AI model across several devices at once. Your laptop, a friend's desktop and a phone each hold part of the model and run it on their own GPU, in a browser tab. Together they run a model none of them could run alone.

There is nothing to install and no account. The model runs on your devices, not on a server.

## How it works in 30 seconds

1. One device opens [duga.app/room](/room) and starts a room. It gets a code like `4TK-G9P`.
2. Other devices join with the code, a link or a QR code. Each one gives the room some memory.
3. Someone picks a model and presses **Start the model**. Each device downloads only its part.
4. Everyone in the room can ask the model questions.

One laptop is enough for the smallest model. More devices let you run bigger ones:

| Model | Memory the room needs |
|---|---|
| Qwen3 1.7B | 5.6 GB at a 16K context, 4 GB at 8K |
| Qwen3.8 27B | 17 GB |
| Qwen3.6 35B MoE | 22.5 GB |

:::caution[A room is a shared conversation]
Everyone in a room can see what is asked, unless the host limits it. Run rooms with people you would share a document with. See [Privacy](/docs/privacy).
:::
