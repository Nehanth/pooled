:::caution[Preview: not on npm yet]
The `@pooled/openclaw` plugin is a proof of concept. It isn't on npm or in OpenClaw's plugin catalog, and runs from a Pooled checkout.
:::

[OpenClaw](https://github.com/openclaw/openclaw) is a self-hosted agent. The `@pooled/openclaw` plugin adds **Pooled** as its model provider. Pick it, and the OpenClaw gateway becomes a device in a Pooled room: it holds part of the model on its own GPU. Other machines, browser tabs and phones hold the rest. No API key, no cloud model.

## Set it up

You need Node 22 or newer and OpenClaw 2026.9.6 or newer, on a machine with a GPU (Linux with Vulkan, or macOS 26+).

<Steps>

1. **Get Pooled and the plugin's dependencies.**

   ```sh
   git clone https://github.com/Nehanth/pooled.git && cd pooled
   (cd packages/room-node && npm install --omit=dev)
   ```

2. **Install OpenClaw and the plugin.**

   ```sh
   npm install -g --allow-scripts=@google/genai,esbuild,koffi,protobufjs,openclaw openclaw@2026.9.7
   openclaw plugins install --link --accept-capabilities --force "$PWD/packages/openclaw"
   ```

3. **Pick Pooled.** Run `openclaw onboard` and choose **Model/auth provider → More… → Pooled**.

4. **Start or join a room.**
   - **Start a room on this device**: pick the model (the 35B MoE is the one for agent work), the GPU memory to give and how many devices to wait for. It prints the room code.
   - **Join a room**: enter the code and the GB to give.

5. **Add more devices.** Open `https://pooled.run/r/<CODE>` in a browser, or run this on another machine with a checkout:

   ```sh
   node packages/room-node/join.mjs <CODE> --gb 12 --name mac-studio
   ```

</Steps>

:::note
The link onboarding prints, `pooled.run/room/<CODE>`, doesn't open. Use `pooled.run/r/<CODE>`.

**Join a room** and `join.mjs` can't answer the room page's **Allow / Deny** yet. To bring them into a room started on pooled.run, first turn off **Room settings → Joining → Ask before new devices join**.
:::

Problems show in the OpenClaw chat as `Pooled: …`, for example waiting for devices or not enough memory.

:::caution[Use rooms of your own devices]
A room the plugin starts lets in anyone with the code. Devices that hold layers see OpenClaw's prompts and could steer its tool calls. Keep OpenClaw's approvals on for `exec` and writes. See [Details](#who-can-see-and-steer-what).
:::

## Details

### Config

Onboarding writes `plugins.entries.pooled.config`. Each key can be overridden by an environment variable.

| Key | Variable | Meaning |
|---|---|---|
| `mode` | `POOLED_MODE` | `host` or `join` |
| `code` | `POOLED_CODE` | The room code, 4 to 6 characters |
| `model` | `POOLED_MODEL` | The model a host starts |
| `pledgeGB` | `POOLED_PLEDGE_GB` | GPU memory this device gives |
| `minDevices` | `POOLED_MIN_DEVICES` | Devices to wait for before dealing the layers (default 1) |
| `waitSeconds` | `POOLED_WAIT_S` | How long a request waits for devices or the model (default 120) |
| `ctx` | `POOLED_CTX` | Context to ask for (default: the model's largest) |
| `signal` | `POOLED_SIGNAL` | A PeerServer `host:port` |
| `modelDir` | `POOLED_MODELS` | Local model files instead of downloads |
| `name` | `POOLED_NAME` | This device's name in the room |
| `page` | `POOLED_PAGE` | A room page other than pooled.run |
| `allowApiClients` | `POOLED_ALLOW_API` | Host: also answer other devices' API requests. On by default. |

Non-interactive: `openclaw onboard --non-interactive --auth-choice pooled` with `POOLED_MODE`, `POOLED_CODE`, `POOLED_MODEL` and `POOLED_PLEDGE_GB`.

On macOS, Dawn runs on Metal and needs macOS 26 or newer. If you copied the package from a zip or a download, run `xattr -d com.apple.quarantine` on `dawn.node`.

### Results

With Qwen3.6 35B MoE on a DGX Spark and a Mac Studio, the agent passed 4 or 5 of 5 test tasks, with no malformed tool calls. Two computers decoded at about 16 to 32 tok/s. Full tables: [docs/openclaw-poc.md](https://github.com/Nehanth/pooled/blob/main/docs/openclaw-poc.md).

### Limits

- **Cold first call.** The first call after the gateway starts reads OpenClaw's whole prompt (14-18K tokens): about a minute on two computers. A gateway restart starts cold again.
- **Splitting costs speed.** Each token pays a network hop, so split only a model that doesn't fit on one device.
- **Join mode** tells OpenClaw the room has 32K of context, whatever the host runs.
- **Install size** is about 156 MB (Dawn for five platforms).
- **Small models**: the 1.7B gets a file-tools-only profile. Use the MoE.
- **Windows** is untested.

### Who can see and steer what

- Other devices' room pages show "answering…" stand-ins, never OpenClaw's prompts or tool calls.
- **Devices that hold layers see the conversation anyway.** They process every token's hidden state, which carries the files and tool results. A bad device could also choose the model's output, including the tool calls OpenClaw runs.
- **Join mode trusts the room's host with everything.** If the real host is down, anyone could register that code on the public signaling server.
- **Guests** can ask their own questions, which queue with OpenClaw's. Turn `allowApiClients` off to keep them out.

See also [Terminal](/docs/terminal), which uses the same headless room node, and [Privacy](/docs/privacy).
