Two things get released: the site at [pooled.run](https://pooled.run), which deploys from `main` (so **Unreleased** changes are usually live), and the `@pooled/cli` package.

## Releases

| Version | Date | Summary |
|---|---|---|
| [1.0.0](https://github.com/Nehanth/pooled/releases/tag/v1.0.0) | 2026-09-27 | The first stable release. Qwen 3.6 35B MoE in rooms, Code mode, long context (16K on the 27B, 32K on the MoE), room checkpoints, the new landing page and the room at `/room`. |
| [0.2.0](https://github.com/Nehanth/pooled/releases/tag/v0.2.0) | 2026-09-07 | Demo release: Qwen 3.8 27B across a MacBook and an iPhone in browser tabs at 10.7 tok/s. |
| 0.1.0 | 2026-08-29 | First public demo: Qwen 3.8 27B split across browser tabs over WebRTC, on Pooled's own WebGPU engine. |

Pooled was called SwarmLLM before September 2026. Entries from before the rename keep the old name.

### pooled serve

`@pooled/cli` 0.2.1 is on npm: Chat Completions, Responses and Messages with tool calling, six-character room codes and `#k=` invite links.

```bash
npx @pooled/cli@latest serve 4TKG9P
```
